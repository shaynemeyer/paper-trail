# Review Action

1. Read `context/current-feature.md` and the source spec, if identifiable.
2. Determine the feature diff against the documented base branch without changing git state.
3. Audit goals met, missing or partial behavior, defects, security, scope creep, compatibility, and meaningful test coverage.
4. Follow repository conventions and automated-check configuration; do not manufacture style findings.
5. Report actionable findings first with file locations, risks, and specific fixes. Then map each goal to evidence.
6. End with `Ready to complete` or `Needs changes`, and state the blocking items. If there are no findings, say so explicitly.
